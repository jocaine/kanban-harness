# 市场分析

相关：[[positioning]]、[[rejected]]

## 核心定位（2026-05-12 确立）

**差异化锚点**：竞品提供编排积木（用户自己搭），KH 提供成品团队（开箱即用）。个人开发者社区的核心痛点是"精力分散"，而非"框架不够灵活"。

## 开源视角

- Hermes 支持 tool use，适合高频低成本的本地调研任务
- Docker Compose 是个人开发者最熟悉的一键部署方式
- SQLite 满足单机部署需求，无需上 PostgreSQL

## 商业视角

- 企业级多 Agent 编排工具（如 AutoGen Enterprise）定价高、配置复杂
- 个人到小团队（1-5 人）的"AI 团队"市场尚无明确领导者
- 本地部署 + 隐私保护是商业客户的核心诉求之一

## 需持续跟踪的信号

- 竞品在个人开发者市场的定价策略变化
- 是否有新的本地 LLM 推理引擎出现（影响 Hermes 选型）
- Docker/本地部署生态的变化趋势
